# Pedidos de Malhas — app offline

Aplicativo de pedidos de malhas que funciona **sem internet**, instalado na tela inicial do celular.

**Instalar no iPhone:** abra o endereço deste app no **Safari** → toque em **Compartilhar** → **Adicionar à Tela de Início**.
**Android:** abra no Chrome → menu ⋮ → **Instalar app**.

Os pedidos ficam guardados **somente no aparelho** de quem usa; nada é enviado para a internet.
Use **Exportar backup** (menu ⋮ da lista) com frequência para guardar uma cópia.

Este repositório contém apenas os arquivos do app, gerados a partir do projeto principal.
